Deploy WhatsApp Bot

Select a session to deploy a WhatsApp bot. Copy the session string and use it in your bot configuration.

Deployment Guide
  1. Generate a session on the Pair Site
  2. Come back here and find your session under Sessions
  3. Click Deploy to get your session string
  4. Copy the Dark_Ima=… string
  5. Paste it in your bot's SESSION_ID environment variable
  6. Download creds.json and place it in your bot folder
  7. Start your bot with npm start
